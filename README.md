# VOCAB CLASH

## 把背單字，變成一場遊戲。

和朋友來一場單字對戰，或選擇適合自己的難度，隨時開始練習。遇到不熟的單字，就把它留下來：聽發音、翻卡背誦，再用今日複習確認自己是否記得。

VOCAB CLASH 是一款以繁體中文介面呈現的英文單字對戰與複習工具，適合學生、英文自學者，以及想換個方式練習英文的人。不必註冊，輸入暱稱就能開始。

**10,000 個不同詞條｜40,000 道題目｜好友對戰｜AI 分級陪練｜個人單字庫**

| 功能 | 可以做什麼 |

| AI 分級陪練 | 不用等朋友上線，自選難度或類型，依自己的步調練習。 |

## 怎麼玩

### 揪朋友對戰

兩人開啟同一個遊戲網址並輸入暱稱。一人按「建立房間」，將四碼房號分享給朋友；另一人輸入房號後按「加入」。雙方到齊後，由房主開始。

每局共 10 題。雙方準備完成後，先看題目約 2 秒；選項出現時，才開始完整的 10 秒作答時間。較快就緒的玩家會先等待，不會提前扣除另一人的作答秒數。

單局結束後可查看分數與作答紀錄。雙方都按「再戰一局」，即可在原房間繼續，累計勝場與對戰次數。

### 一個人練習

在 AI 陪練區選擇「綜合、基礎、中階、進階、高階、魔王、片語、流行語」，再按「開始練習」。

難度選擇只影響單人題組，不會改動好友對戰規則。AI 是內建的模擬對手，使用現有題庫，不需要填入模型 API 金鑰，也不是即時生成無限新題。

### 把想記住的單字留下來

每題公布答案後，或在賽後複習清單中，點擊書籤即可收藏。實心書籤表示已收藏，再點一次可取消。

在「我的單字庫」中，可以搜尋、篩選、播放發音、開始背誦，或進行單字再測。主動收藏不會增加答錯次數；取消收藏也不會刪除原有的錯題紀錄。

第一次使用，可點右上角「教學」逐步認識各項操作。教學不會真的建立房間、開始比賽或新增學習紀錄。

## 題庫與題型

題庫包含 **10,000 個不重複詞條，每個詞條對應 4 種題型，共 40,000 道題目**。內容涵蓋基礎至高階單字、片語、慣用語、流行語與縮寫。

| 題型 | 練習方式 |
| --- | --- |
| 英選中 | 看英文詞條，選出對應的中文意思。 |
| 中選英 | 看中文意思與詞性，選出對應的英文詞條。 |
| 英文釋義 | 根據英文解釋，辨識對應詞條。 |
| 拼字辨識 | 根據題意，在選項中辨識正確拼法。 |

英選中不附上洩漏答案的英文解釋；中文選英文不提供部分英文字母或挖空提示。完整釋義保留在學習與複習頁面。

> 10,000 是「詞條」總數，包含片語與流行語，不等於 10,000 個純單字。選項打亂不另外計入題目數量。

## 對戰計分

選項出現後的第一秒內答對，基礎分為 **200 分**。之後依每秒區間遞減，不是每毫秒扣分，也不是固定等差遞減。

第一次答對不加成；連對第 2 題為 **×1.05**，第 3 題為 **×1.10**，之後每多連對一題增加 0.05。答錯或逾時會中斷連對，但不會扣除先前累積的分數。

第 10 題另有 **×3** 倍率。累計勝場只在單局結算時顯示；未完成的中止局不計入勝負。

<details>
<summary>查看完整時間級距與計算方式</summary>

以下以剩餘秒數 `t` 表示：

| 剩餘時間 | 基礎分數 |
| --- | ---: |
| 9 < t ≤ 10 | 200 |
| 8 < t ≤ 9 | 174.38 |
| 7 < t ≤ 8 | 149.61 |
| 6 < t ≤ 7 | 125.75 |
| 5 < t ≤ 6 | 102.90 |
| 4 < t ≤ 5 | 81.17 |
| 3 < t ≤ 4 | 60.72 |
| 2 < t ≤ 3 | 41.76 |
| 1 < t ≤ 2 | 24.64 |
| 0 < t ≤ 1 | 10 |

上表為基礎分的顯示值。例如剩 9.6 秒與 9.1 秒答對，同樣屬於 200 分區間；剩 9.0 秒則進入下一級。

```text
當題得分 = 時間基礎分 × 連對倍率 × 第 10 題倍率
```

基礎分保留內部計算精度，套用倍率後四捨五入至小數點後兩位。答錯或時間到為 0 分。

雙方都提交答案或時間到後，才同步公布結果。對戰以房主或中繼伺服器收到答案的時間計分，網路延遲仍可能影響得分。

單字庫內的複習與再測不限時，不影響對戰勝場。

</details>

## 複習與學習紀錄

「今日複習」會整理已到期的詞條，每次最多 10 題；「單字再測」則從目前篩選的收藏與錯題中抽題。詞條不足時，不會重複湊成 10 題。

複習作答後才顯示解答與發音。答對會依排程逐步延長複習間隔，答錯則較早再次安排；不是反覆點幾次答對，就直接認定已經熟記。

學習進度只呈現必要的作答數據。另有「單字量級距」，依不同難度的首次詞義作答估計**本題庫內**可辨識的單字量；樣本不足時顯示「累積中」。

<details>
<summary>單字量級距與統計範圍</summary>

單字量估計以題庫中的 9,499 個純單字為範圍，不包含片語、流行語與 Catch-22。只使用符合條件的首次詞義作答，不把反覆練同一個單字當作認識更多字。

至少累積 50 個不同單字，且五個難度各至少 10 個，才顯示區間。這是遊戲的參考門檻，不是標準化測驗。

結果不代表使用者認識的全部英文單字量，也不換算考試成績。題型、計時、猜測與個人練習方式都可能影響估計。

目前作答統計最多保存 20,000 筆紀錄，達上限時會提示。這個上限與 40,000 道可用題目的題庫容量不同。

</details>

## 資料保存在你的瀏覽器

收藏、錯題與學習紀錄儲存在裝置的瀏覽器本機資料庫，**不是存在 GitHub 帳號，也不會自動跨裝置同步**。暱稱只是對戰顯示名稱，不是獨立的登入帳號。

在同一裝置、同一瀏覽器設定檔與相同網站來源下，正常關閉瀏覽器後，已成功儲存的紀錄可繼續讀取。但無痕模式、清除網站資料、儲存限制或瀏覽器政策仍可能使紀錄消失；若只能暫存於當前頁面，遊戲會顯示提示。

**換裝置、換網址或更新網站前，請先到「我的單字庫 → 備份與儲存」匯出備份，再於需要的裝置或網站匯入。** 多人共用同一個瀏覽器設定檔時，也會共用同一份本機學習資料。

請勿將個人的單字庫備份上傳到公開的 GitHub 儲存庫。

## 操作與使用提醒

點擊選項，或在電腦上使用 `1–4`／`A–D` 作答。右上角提供教學、音效與設定入口；設定中可調整答對音效、震動，以及「跟隨系統／關閉動態」。關閉介面動態不會影響計時、計分或音效。

發音使用瀏覽器或裝置提供的英文合成語音，並非逐字真人錄音。可用語音、音色與震動效果依裝置及瀏覽器而定；內嵌頁面也可能受到限制。

好友對戰需要網路。預設直連可能受公司防火牆、路由器或行動網路限制；必要時可由網站部署者配置中繼服務。雙方須使用相容版本與相同連線方式。

對戰時請保持遊戲頁面在前景，房主不要關閉或重新整理頁面。短暫斷線會嘗試同步與恢復，保留期為 30 秒；關閉頁面後不保證能恢復原房間。

<details>
<summary>使用 GitHub Pages 發布</summary>

靜態發布所需的檔案已整理在 Pages 包內，解壓縮後維持以下結構：

```text
.
├── index.html
├── .nojekyll

```

`index.html` 已內建題庫、樣式、圖示與前端程式，不需要另外上傳原始詞庫 CSV、題庫 JSON 或使用者資料。不要只將 ZIP 壓縮檔上傳到儲存庫。

將檔案放在 Pages 的發布目錄，依選定的分支與目錄設定發布。後續更新時，先匯出學習資料備份，再用新 `index.html` 覆蓋原位置，保留 `.nojekyll` 與第三方授權說明。

發布完成後，玩家重新載入原本網址並重新開房。GitHub Pages 只提供靜態網站，不會執行 Node.js／WebSocket 中繼伺服器；中繼服務需要另外部署。

更多版本與更新資訊請見 [使用說明](./GUIDE.md)。

</details>
